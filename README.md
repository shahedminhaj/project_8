# Commonplace

Community events frontend for finding and organizing local volunteer opportunities.

The Next.js frontend and its dependencies live in [`project8/`](./project8/). A backend can be developed separately in its own folder.

## Run the frontend from the repository root

```bash
npm run dev
```

Other frontend commands:

```bash
npm run build
npm run start
npm run lint
```

If frontend dependencies have not been installed, run:

```bash
npm run install:app
```

## Project layout

- `project8/` — Next.js frontend.
- `backend/` — reserved for a separately developed backend.
